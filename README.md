# Clínica em Dia — app no celular

Página de entrada que permite instalar o sistema da Dra. Camila Rodrigues (Médica Veterinária) como app na tela inicial do celular (Android e iPhone), com a logo dela como ícone.

Ao abrir pelo ícone, a página leva direto ao sistema (Google Apps Script). Esta página não guarda nenhum dado da clínica.
