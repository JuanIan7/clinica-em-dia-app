Abrir o sistema agora

No Samsung / Android

  1. Abra este link no Chrome ou no Samsung Internet.
  2. Toque em Instalar app no celular (acima). Se o botão não aparecer: no Chrome, menu ⋮ → Instalar app; no Samsung Internet, menu ≡ → Adicionar página a → Tela inicial.
  3. Pronto: o ícone com a sua logo aparece na tela inicial. É só tocar nele.

No iPhone

  1. Abra este link no Safari.
  2. Toque em Compartilhar (o quadrado com a seta para cima).
  3. Escolha Adicionar à Tela de Início e toque em Adicionar.

Na primeira vez que abrir pelo ícone, o Google pode pedir para entrar na conta: use a mesma conta Google de sempre. Os dados continuam guardados no Google, como hoje.
